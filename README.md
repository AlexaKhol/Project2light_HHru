# Project2light_HHru
## 📖Контекст данных

Данный проект представляет собой исследовательский анализ данных (EDA) базы вакансий, опубликованных на портале **hh.ru** в мае и июне 2024 года. 

**Цель проекта** — изучить текущие тенденции на рынке труда для специалистов в области аналитики данных и системного анализа. 

## 📊Основные результаты
В ходе исследования были получены следующие данные:
*   **Уровень зарплат:** Вакансии имеют среднюю зарплату примерно от 100 000 рублей до 150 000 рублей. Максимальная зарплата составляет 497 500 рублей.
*   **География и компании:** Наибольшая концентрация вакансий традиционно сосредоточена в Москве и Санкт-Петербурге, однако значительная часть вакансий (около 20%) предполагает удаленную работу. Среди основных работодателей выделяется СБЕР.
*   **Грейды:** Рынок ориентирован на специалистов уровня Junior+ и Middle (около 90% всех предложений). Вакансий для стажеров (Junior) значительно меньше, что говорит о высоких требованиях к базовым навыкам при входе в профессию. Вакансий для и Senior-специалистов так же мало (менее 10% от общего числа вакансий) - вероятно, такие специалисты привлекаются по другим каналам.
*   **График и занятость:** Подавляющее большинство вакансий (более 90%) предлагают полную занятость.
*   **Навыки (Hard & Soft Skills):** Самыми востребованными жесткими навыками являются **Анализ данных** (сюда входит **Python**), **SQL** и **Документация**. В блоке "мягких" навыков работодатели чаще всего требуют аналитическое мышление и навыки коммуникации.

## Структура данных
Данные представлены одной таблицей `public.parcing_table`, содержащей спарсенные объявления:

| Столбец | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | int4 | Идентификатор объявления (Первичный ключ) |
| `name` | varchar | Название вакансии |
| `published_at` | timestamp | Дата публикации вакансии |
| `employer` | varchar | Название компании-работодателя |
| `department` | varchar | Отделение компании |
| `area` | varchar | Расположение (город) |
| `experience` | varchar | Требуемый опыт (грейд) |
| `schedule` | varchar | График работы |
| `employment` | varchar | Тип занятости |
| `salary_from` / `salary_to` | numeric | Нижняя и верхняя границы зарплаты |
| `salary_bin` | varchar | Категория «зарплатная вилка» |
| `key_skills_1..4` | varchar | Ключевые навыки (Hard Skills) |
| `soft_skills_1..4` | varchar | Мягкие навыки (Soft Skills) |


## 🛠️Инструменты и структура проекта
Анализ выполнен на языке SQL с использованием PostgreSQL (в среде DBeaver).
- /Scripts/: Папка с SQL-скриптом (для удобства есть общий скрипт и скрипты по каждому запросу)
- Выводы по полученным результатам запросов представлены непосредственно в коде каждого запроса Q1, Q2... (Выводов нет в общем скрипте, чтобы не перегружать код)

## 📁Запуск проекта
1) Клонируйте репозиторий;
2) Откройте файлы из папки /sql_scripts/ в вашей СУБД или с помощью приложения;
3) Выполните скрипты для получения аналитических выгрузок.
